# Articles

### All vignettes

- [Fitting MNAR models in
  missingHE](https://angabrio.github.io/missingHE/articles/Fitting_MNAR_models_in_missingHE.md):

  This tutorial shows few examples of how models in missingHE can be
  fitted under different types of missing not at random (MNAR)
  assumptions for the outcome variables in trial-based CEA.

- [Introduction to
  missingHE](https://angabrio.github.io/missingHE/articles/Introduction_to_missingHE.md):

  Start here if this is your first time using missingHE. You will learn
  the basic theory behind the package and the most important functions
  and their arguments, which allow you to fit different types of models
  to handle missing values in trial-based CEA.

- [Longitudinal models in
  missingHE](https://angabrio.github.io/missingHE/articles/Longitudinal_models_in_missingHE.md):

  This tutorial shows some examples of how to specify, customise and fit
  a longitudinal missingness model in missingHE when performing
  trial-based CEA using longitudinal data.

- [Model and output customisation in
  missingHE](https://angabrio.github.io/missingHE/articles/Model_customisation_in_missingHE.md):

  This tutorial shows few examples of how different types of models and
  their output can be customised in missingHE based on the needs of the
  user when performing trial-based CEA.
