# Package index

## Package Overview

- [`missingHE`](https://angabrio.github.io/missingHE/reference/missingHE-package.md)
  [`missingHE-package`](https://angabrio.github.io/missingHE/reference/missingHE-package.md)
  : missingHE: Missing Cost Effectiveness Models

## Model Fitting

Functions for fitting Bayesian missingness models to individual-level
CEA data.

- [`selection()`](https://angabrio.github.io/missingHE/reference/selection.md)
  : Bayesian Selection Models
- [`pattern()`](https://angabrio.github.io/missingHE/reference/pattern.md)
  : Bayesian Pattern Mixture Models
- [`hurdle()`](https://angabrio.github.io/missingHE/reference/hurdle.md)
  : Bayesian Hurdle Models
- [`lmdm()`](https://angabrio.github.io/missingHE/reference/lmdm.md) :
  Bayesian Longitudinal Missing Data Models

## Plotting & Diagnostics

Functions for visualising model fit, MCMC convergence outputs.

- [`plot(`*`<missingHE>`*`)`](https://angabrio.github.io/missingHE/reference/plot.missingHE.md)
  : Plot method for the imputed data
- [`diagnostic()`](https://angabrio.github.io/missingHE/reference/diagnostic.md)
  : Diagnostic checks for assessing MCMC convergence of a Bayesian model
- [`ppc()`](https://angabrio.github.io/missingHE/reference/ppc.md) :
  Posterior predictive checks for assessing the fit to the observed data
  of a Bayesian model
- [`postsum()`](https://angabrio.github.io/missingHE/reference/postsum.md)
  : Postsum method for inspecting summary posterior estimates of a
  Bayesian model
